# ثبت‌یار v4 Beta — بازسازی‌شده

نسخه بازسازی‌شده بر پایه آرشیو v4 beta.

## ویژگی‌ها
- رابط فارسی و RTL
- فونت محلی **IRANSansWeb** داخل `assets/fonts`
- بدون وابستگی به Google Fonts یا فونت خارجی
- جستجو، دسته‌بندی و مرتب‌سازی ثبت‌نام‌ها
- تفکیک فعال، پیش‌رو و منقضی
- لینک مستقیم سامانه رسمی
- گزارش ربات روزانه برای بررسی لینک‌های رسمی
- آماده برای GitHub Pages / Cloudflare Pages / هاست استاتیک

## ساختار داده
اطلاعات قابل نمایش در `data/registrations.json` قرار دارد.
تنها مواردی را به عنوان «فعال» وارد کنید که وضعیت و مهلت آنها از منبع رسمی تأیید شده باشد.

## ربات روزانه
`python scripts/update.py`

ربات فقط لینک‌های دامنه‌های رسمی تعریف‌شده در `data/sources.json` را بررسی می‌کند و تاریخ‌ها را حدس نمی‌زند.
